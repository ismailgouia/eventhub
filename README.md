
# EventHub

**EventHub** est une application web de gestion des événements universitaires développée avec Angular 22.

Elle permet aux étudiants de découvrir les événements organisés par les clubs universitaires et de réserver leurs places. Les organisateurs peuvent gérer les événements et suivre les réservations.

## Objectifs du projet

- Faciliter la découverte des événements universitaires.
- Permettre aux étudiants de réserver des places.
- Offrir aux organisateurs un espace de gestion des événements.
- Centraliser les informations relatives aux événements et aux réservations.

## Technologies utilisées

- Angular 22
- TypeScript
- HTML5
- CSS3
- Git et GitHub

## Installation et lancement

### Prérequis

- Node.js
- npm
- Angular CLI

### Installation

Cloner le repository :

```bash
git clone https://github.com/ismailgouia/eventhub.git
```

Accéder au dossier :

```bash
cd eventhub
```

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
ng serve
```

Ouvrir ensuite http://localhost:4200 dans le navigateur.
